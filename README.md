# Spam Email Classifier

## 📌 Description
This project detects whether a message is spam or not using NLP and Machine Learning.

## 🚀 Technologies Used
- Python
- Scikit-learn
- CountVectorizer
- Naive Bayes

## 🤖 Model Used
Multinomial Naive Bayes

## ⚙️ Features
- Text preprocessing
- Word vectorization
- Spam prediction

## ▶️ How to Run
pip install pandas scikit-learn
python main.py

## 📷 Example Output
Enter message: Free prize now  
Prediction: Spam
